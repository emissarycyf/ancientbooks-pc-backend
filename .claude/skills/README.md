# 技能目录

该目录用于存储适用于Claude Code的项目特定技能。

## 什么是技能？

技能是一组可重复使用的指令，帮助Claude理解项目相关的流程、模式和最佳实践。

## 如何添加技能

1. 在此目录中创建一个新的 Markdown 文件（例如：`my-skill.md`）
2. 在文件中添加您的技能说明
3. 在提示中使用 `/skill-name` 引用该技能。

## 技能结构示例

```markdown
# 技能名称

## 描述
简要说明该技能涵盖的内容。

## 指令
当此技能激活时，Claude 需要遵循的逐步操作说明。

## 示例
与该项目相关的代码示例或模式。
```
```
